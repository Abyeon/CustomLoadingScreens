# Custom Loading Screens
A quick and dirty re-implementation of VanillaPlus's FancyLoadingScreens with custom image paths.

## How to use
* Open up the config UI with `/customloadingscreens`
* Press the `Add Image` button
* Find your image in the file browser
* Add it
* Go teleport!

## How to install
This plugin is officially a part of the main Dalamud plugin repository testing branch.

* Open up `/xlsettings`
* Go to the `Experimental` tab
* Tick the `Get plugin testing builds` box
* Save
* Go to `/xlplugins` and install Custom Loading Screens!
